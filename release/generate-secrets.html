สร้างรหัสภายใน LINE Archive

เปิดไฟล์นี้จากเครื่องแล้วกดสร้าง ระบบสุ่มรหัสในเบราว์เซอร์ของคุณ ไม่มีการส่งข้อมูลออก ไม่มีการบันทึกลงไฟล์หรือ localStorage

คัดลอกแต่ละค่าไปตั้งชนิด Secret ใน Cloudflare และเก็บใน password manager ของคุณ รหัสสองค่านี้ต้องไม่เหมือนกัน อย่าส่งลงแชท ปิดหน้านี้เมื่อเก็บค่าแล้ว หากมีข้อมูลจริงอยู่แล้ว อย่าเปลี่ยนรหัสเข้ารหัสโดยไม่มีแผนเชื่อม Google ใหม่
